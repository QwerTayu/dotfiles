# すでに ~/.claude/skills/ に同じ名前のフォルダがあれば飛ばす。消すときはこの行と ~/.claude/skills/<名前> を手で消す。
# 例:
# owner/repo skills/foo
# owner/repo skills/bar v1.2.0
